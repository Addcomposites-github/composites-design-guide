## Before You Post Anything — Quick Check

Run this in 2 minutes:

1. Open https://opencomposites.addcomposites.com — does it load?
2. Type "carbon fibre drone arm" in Analyze → does it give output?
3. Search "ply drop-off" in Knowledge Base → do results appear?
4. Check the stat on the homepage shows **56** articles (not 54+)

If anything is broken, don't post. Contact the dev team.

## Platform-Specific Tips

**Reddit**
- Do NOT post the same text to multiple subreddits — each post is customised. Launch pad has different copy per sub.
- Reply to every comment within 24 hours. Silence kills traction.
- Best times: Tuesday–Thursday, 8–10am EST

**Hacker News**
- Title must start with "Show HN:" — already in the launch pad
- Post between 9am–12pm SF time (noon–3pm EST) on a weekday
- Reply to ALL top-level comments within the first hour — HN ranking rewards engagement velocity

**LinkedIn carousel**
- Upload all 10 slides as images (not the PPTX)
- First image = hook. Users swipe to see more.
- Add caption from the launch pad + 3–5 hashtags

**Composites Central / Talk Composites**
- These are forum communities — read a few threads first to understand the tone
- Do NOT use marketing language. Write like an engineer talking to other engineers.
- Register an account and make at least one helpful reply before posting the launch
