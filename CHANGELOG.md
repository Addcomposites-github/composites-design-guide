# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-25

### Added
- Full-stack web application (React 19 + FastAPI)
- Photo-to-Plan AI analysis powered by Claude (BYOK - Bring Your Own Key)
- Knowledge base with 56 articles covering 10 topic areas (67,000+ words)
- Materials database with 15+ composite material systems
- Manufacturing process recommendation engine (10 processes)
- Per-part cost estimation calculator
- CLT (Classical Lamination Theory) calculator
  - ABD stiffness matrices and effective moduli
  - 4 failure criteria: Max Stress, Tsai-Wu, Tsai-Hill, Hashin
  - Laminate optimization across 6 standard families
- Sandwich panel analysis and optimization (6 failure modes, 7 core materials)
- Bolted joint analysis (bearing, net-tension, shear-out, cleavage checks)
- Stacking sequence rule checker (symmetry, balance, 10% rule, consecutive plies)
- MCP server for AI assistant integration (8 tools)
- Community feedback system via GitHub Issues
- Replit deployment configuration
- Open-source knowledge base (CC BY 4.0)
